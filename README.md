# Simple Calculator
A beginner-friendly calculator application built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Repeated calculations

## Technologies Used

- Python

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:
